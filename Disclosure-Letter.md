# Disclosure Letter

To the Fast / Pi² Labs team,

Over approximately five months I independently evaluated publicly available verification paths within the Fast ecosystem.

The review included:

- real-funds testing;
- wallet analysis;
- explorer analysis;
- public documentation review;
- repository review;
- direct communication with project representatives.

The resulting report does not claim fraud, protocol failure, or exploitable vulnerabilities.

Instead, it documents several areas where public verification claims are currently not independently reproducible through publicly available artifacts.

This work should be considered an independent reproducibility review rather than a traditional vulnerability disclosure.

Given the time invested, real-funds testing performed, and evidence collected, I respectfully request consideration for compensation, acknowledgment, or a research grant.
